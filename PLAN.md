# PLAN — Backend auth: Google OAuth (v1)

## Context

- `frag-discovery-backend/` is **empty** — the new FastAPI backend hasn't been started.
- The frontend is fully built and runs against the reference frag-scraper Flask backend on `:3232` (no auth, single user).
- AGENTS.md locks in: Python + FastAPI, bearer-token sessions, backend runs anywhere (local / Oracle free VM / container).
- **Decision (this session):** Google OAuth is the **only** sign-in method for now. No email+password, no email verification, no emailed tokens — Google already verifies email.

## Locked decisions (from user)

1. **Flow:** Google Identity Services button in the frontend → frontend POSTs the **ID token** (JWT) to `POST /api/auth/google` → backend verifies the signature against Google's public keys (`google-auth`, JWKS cached) → upserts user → issues an opaque bearer session. **Only `GOOGLE_CLIENT_ID` needed — no client secret, no outbound calls at login.**
2. **DB:** SQLite (`sqlite:///./data/app.db`). SQLAlchemy 2.0 so Postgres later is a one-line env change.
3. **Scope:** Backend auth only. Frontend Google button/UI is the next pass.

## What this pass builds

1. uv-managed FastAPI project scaffold.
2. `users` + `sessions` schema (opaque bearer tokens, stored as SHA-256 hashes, expiring).
3. `POST /api/auth/google` — verify ID token → upsert user → create session → return token + profile.
4. `GET /api/auth/me` — bearer token → profile. `POST /api/auth/logout` — revoke session (204).
5. Config + CORS + `GET /api/health`.

Out of scope (later passes): email/password, votes/favorites endpoints, recommender, alembic migrations (use `create_all` for now), refresh tokens (sessions are long-lived: 30d TTL via env), frontend login UI.

## API contract (frontend will consume this as-is next pass)

```
POST /api/auth/google        body: { "id_token": "<jwt from GIS>" }
  200 → { "access_token": "<opaque>", "token_type": "bearer",
          "expires_in": 2592000, "user": { id, email, name, picture, created_at } }
  400 → invalid/missing token

GET  /api/auth/me            header: Authorization: Bearer <token>
  200 → { id, email, name, picture, created_at }
  401 → missing/expired/unknown token

POST /api/auth/logout        header: Authorization: Bearer <token>
  204 → session revoked (idempotent)

GET  /api/health             200 → { "status": "ok" }
```

Errors use FastAPI's standard `{"detail": "..."}` JSON shape.

## Key implementation details

- **Deps:** `fastapi`, `uvicorn[standard]`, `sqlalchemy`, `pydantic-settings`, `google-auth` (pulls `requests` + `cachecontrol` for the cached JWKS fetch). Dev: `pytest`, `httpx` (TestClient). `requires-python = ">=3.12"` (3.14.6 available).
- **Config** (`config.py`): `GOOGLE_CLIENT_ID` (required), `DATABASE_URL` (default `sqlite:///./data/app.db`), `FRONTEND_ORIGIN` (default `http://localhost:5173`), `SESSION_TTL_DAYS` (default 30), `ENV`.
- **DB** (`db.py`): `create_engine(..., connect_args={"check_same_thread": False})` for SQLite; `Path.mkdir` for the `data/` dir; `Base.metadata.create_all` in the FastAPI lifespan.
- **Models** (`models.py`):
  - `User`: `id` PK · `google_sub` str unique indexed · `email` str unique indexed · `name` nullable · `picture` nullable · `created_at` · `updated_at` (onupdate).
  - `Session`: `id` PK · `user_id` FK→users `ondelete=CASCADE` · `token_hash` str unique indexed (sha256 hex of raw token) · `created_at` · `expires_at`.
- **Verification** (`auth/google.py`): `id_token.verify_oauth2_token(id_token, requests.Request(), settings.google_client_id)` → claims; reject unless `email_verified is True`; aud is checked by the lib against our client id. Wrap in a small `GoogleClaims` dataclass. This is the single seam tests stub.
- **Sessions** (`auth/dependencies.py`): raw token from `Authorization: Bearer <t>` (HTTPBearer, `auto_error=False`), `sha256(t)` → lookup `Session` joined `User`, check `expires_at > now`, else 401. Token minted with `secrets.token_urlsafe(32)`.
- **Routes** (`auth/routes.py`): login upserts by `google_sub` (refreshes name/picture/email), creates a session, returns `AuthResponse`; `/me` returns `UserOut`; `/logout` deletes the session row and returns 204.
- **CORS** (`main.py`): allow `FRONTEND_ORIGIN` origin, `Authorization` + `Content-Type` headers, standard methods. Harmless in dev (Vite proxies, same-origin); needed for prod deployments.
